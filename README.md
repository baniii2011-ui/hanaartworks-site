# HanaLumen / HanaArtworks

Kjo repo përmban faqen përcaktuese statike për HanaLumen (HanaArtworks) — llampa dekorative të punuara me dorë.

Çfarë përfshin:
- index.html — Ballina / hero
- about.html — Rreth nesh
- products.html — Koleksioni
- contact.html — Forma e kontaktit (Formspree placeholder)
- styles.css — CSS i përgjithshëm

Si ta publikosh (GitHub Pages):
1. Shko tek Settings → Pages në repo dhe siguro që branch të jetë `main` dhe folder `/ (root)`.
2. Nëse dëshiron domain personal, shto një file `CNAME` me domain-in tënd në root.
3. Për formularin e kontaktit, krijo një endpoint në Formspree (https://formspree.io) dhe zëvendëso `action` në contact.html me URL-në e formës.

Personalizime të rekomanduara:
- Zevendesoni `your-email@example.com` me email-in tuaj në kontakt dhe footer.
- Zëvendësoni imazhet e placeholders me fotot reale të produkteve (folder `assets/` ose në rrugë relative).
- Për logo, shto një imazh në /assets/logo.png dhe ndrysho header.

Nëse dëshiron, unë mund të:
- Konfiguroj Formspree për ty (duhet të jepni email)
- Ndihmoj me blerjen dhe konfigurimin e domain-it
- Shtoj galeri të avancuar ose dyqan online në të ardhmen
